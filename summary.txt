1. Question 1: Printing the Page Table of a Process (vmprint)
Implementation Summary: Implemented the vmprint() kernel function in vm.c which walks the page directory of the calling process for user-space addresses below KERNBASE. Registered it as system call SYS_vmprint across syscall.h, user.h, usys.S, syscall.c, and defs.h. Created user program pttest.c to invoke it.  
Output Analysis: At start-up, pttest displays the initial user-space mapping (text, data, stack guard, and user stack). After executing sbrk(4 * 4096), a second invocation of vmprint() shows exactly 4 new valid user pages mapped into the heap with present flags (P=1, W=1, U=1), confirming correct page table expansion.  

2. Question 2: Handling Page Faults with Lazy Allocation (faulttest)
Implementation Summary: Modified sys_sbrk() in sysproc.c to increase myproc()->sz without eagerly allocating physical frames. Updated copyuvm() and deallocuvm() in vm.c to skip unallocated lazy entries instead of triggering panics. Added a page_faults counter to struct proc and handled trap T_PGFLT in trap.c by fetching the fault address from register CR2, allocating a zeroed physical frame via kalloc(), mapping it with mappages(), and incrementing the counter. Exposed this via system call getfaults().  
Output Analysis: In faulttest, calling sbrk(32 * 4096) defers physical allocation. Accessing 5 distinct pages triggers precisely 5 lazy page faults, verified by getfaults(). Furthermore, an out-of-bounds write attempt by a child process results in safe termination of only the offending child while the parent process continues execution normally. 

3. Question 3: Page Replacement Algorithms (pagerepl)
Implementation Summary: Developed user program pagerepl.c to simulate FIFO (using a circular pointer) and LRU (tracking reference timestamps) page replacement algorithms on a given reference string.  
Output Analysis: Tested on reference string 7 0 1 2 0 3 0 4 2 3 0 3 2 1 2 0 1 7 0 1:
3 Frames: FIFO yields 15 page faults (25.00% hit ratio); LRU yields 12 page faults (40.00% hit ratio).  
4 Frames: FIFO yields 10 page faults (50.00% hit ratio); LRU yields 8 page faults (60.00% hit ratio).  
5 Frames: FIFO yields 9 page faults (55.00% hit ratio); LRU yields 7 page faults (65.00% hit ratio).  
Conclusion: LRU consistently outperforms FIFO by retaining frequently used pages and avoiding unnecessary replacement thrashing.
